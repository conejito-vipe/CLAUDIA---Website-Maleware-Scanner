# CLAUDIA 3.1.3 - Radar rotates, check view without scrolling, status bar, dashboard with profile names, "fine" is green

- **Radar**: The beam always rotates in the check view and lights up the findings, even if Windows animation effects are switched off. Why: With animation effects switched off the radar stood still.
- **Check view and status bar**: In the program window there is no scrolling any more when everything fits; the check view is more compact. The line "vibecoded with Claude ..." with the number of program lines is at the bottom right of the status bar. "read only" is green after the connection; the duplicate on the right is gone. Why: The page was always 72 pixels taller than the visible area, and a lot of space at the bottom stayed unused.
- **Dashboard**: Each site shows the name of its connection profile as heading (e.g. "Kinderperspektive"); server and folder are shown small below. Why: The long server addresses were hard to read.
- **"Fine" is green**: Lists such as log files, scheduled tasks, known embeds, server settings, JCE profiles or log coverage count as explanation. Checks that otherwise only report "fine" are green. A wrong marking for "no security extension" is fixed; that stays a notice. Why: Several checks were blue although everything was fine in the details.
- **Setup**: The page "Ready to install" no longer shows scroll bars. Why: The content is short; the bars were distracting.

# CLAUDIA 3.1.3 - Radar dreht sich, Prüfungsansicht ohne Bildlauf, Statusleiste, Dashboard mit Profilnamen, "in Ordnung" ist grün

- **Radar**: Der Strahl dreht sich in der Prüfungsansicht immer und lässt die Funde aufleuchten, auch wenn in Windows die Animationseffekte ausgeschaltet sind. Warum: Bei ausgeschalteten Animationseffekten stand das Radar still.
- **Prüfungsansicht und Statusleiste**: Im Programmfenster gibt es keinen Bildlauf mehr, wenn alles hineinpasst; die Prüfungsansicht ist kompakter. Die Zeile "vibecoded with Claude ..." mit der Zahl der Programmzeilen steht unten rechts in der Statusleiste. "nur lesend" steht grün hinter der Verbindung, die doppelte Angabe rechts entfällt. Warum: Die Seite war immer 72 Pixel höher als der sichtbare Bereich, und unten blieb viel Platz ungenutzt.
- **Dashboard**: Jede Seite trägt den Namen ihres Verbindungsprofils als Überschrift (z. B. "Kinderperspektive"); Server und Ordner stehen klein darunter. Warum: Die langen Serveradressen waren unübersichtlich.
- **"In Ordnung" ist grün**: Auflistungen wie Protokolldateien, geplante Aufgaben, bekannte Einbindungen, Servereinstellungen, JCE-Profile oder die Abdeckung der Protokolle gelten als Erläuterung. Prüfungen, die sonst nur "in Ordnung" melden, sind grün. Eine falsche Markierung bei "keine Sicherheits-Erweiterung" ist behoben; das bleibt ein Hinweis. Warum: Mehrere Prüfungen standen blau, obwohl im Detail alles in Ordnung war.
- **Setup**: Die Seite "Bereit zur Installation" zeigt keine Bildlaufleisten mehr. Warum: Der Inhalt ist kurz, die Leisten störten.

# CLAUDIA 2.12.0 - PrestaShop

- **PrestaShop sites are detected and checked**: CLAUDIA now detects PrestaShop (versions 1.7, 8 and 9; 1.6 with limits) and shows its own checks: core (version from app/AppKernel.php, support phase from a built-in table, security advisories from Packagist, comparison of the classes, controllers and src folders with the original from GitHub), settings (parameters.php, dev mode, cookie_key, install and admin folders, file permissions), publicly reachable files and pages, modules and overrides (security advisories where a module is listed on Packagist), employee accounts and super administrators, HTTPS and webservice settings, and code in pages, products, categories and text blocks.
- **Internal**: The PrestaShop checks were secured with a rebuilt PrestaShop test world (SQLite database with ps_employee, ps_configuration, ps_webservice_*, ps_cms_lang and others).

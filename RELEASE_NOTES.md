# CLAUDIA 2.11.0 - Contao

- **Contao sites are detected and checked**: CLAUDIA now detects Contao (version 4.13 and newer, Composer installation; older versions are detected and reported as no longer supported) and shows its own checks: core (version, end of support from a built-in table, security advisories from Packagist, comparison of the core packages contao/core-bundle, manager-bundle and installation-bundle with the original from GitHub), settings (.env, config/parameters.yaml, older localconfig.php: suspicious commands, development mode, APP_DEBUG, APP_SECRET, TRUSTED_HOSTS, allowed upload file types and HTML tags, minimum password length, file permissions), publicly reachable files, Install Tool, Contao Manager and development entry point, packages from composer.lock (security advisories from Packagist, development packages on the live server, own packages), backend administrators (also without two-factor authentication) and code in content elements, modules and page layouts. The general checks that read nothing system-specific run as well.
- **Internal**: The Contao checks were secured with a rebuilt Contao test world (Composer, SQLite database with tl_user, tl_content, tl_module, tl_layout). A check was missing from the Tech Docs list (TYPO3); this is fixed.

# CLAUDIA 2.13.0 - Shopware

- **Shopware sites are detected and checked**: CLAUDIA now detects Shopware 6 (6.5 and newer, Composer installation) and shows its own checks: core (version from composer.lock, support phase from a built-in table, security advisories from Packagist, comparison of the shopware/core, administration and storefront packages with the original from GitHub), settings (.env, dev mode, APP_SECRET, permissions of the .env and the private JWT key), publicly reachable files and pages, packages, plugins and apps (security advisories where listed on Packagist), administrator accounts, HTTPS of the shop addresses, integrations with administrator rights, webhooks, and code in shopping experiences, products, categories, snippets and settings.
- **Internal**: The Shopware checks were secured with a rebuilt Shopware test world (SQLite database with user, integration, webhook, sales_channel_domain, cms_slot_translation and others). The version comparison in security advisories now understands four-part versions (6.6.10.0); this also applies to PrestaShop (1.7.8.11).

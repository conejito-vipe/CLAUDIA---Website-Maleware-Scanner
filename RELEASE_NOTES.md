# CLAUDIA 2.15.0 - More intrusion paths

- **New checks after research into current attacks**: New for WordPress: "Hidden code" (code that hides users, a mismatched db.php, hidden PHP files, placeholder plugins, file names from known attacks) and "Hidden options" (Base64 code in the database, WebSocket scripts in plugin settings). New for Joomla: "Known attacks" (Helix3 below 3.1.2, JCE below 2.9.99.5, cox.json, defacement scripts in template parameters). New for all systems: "Undeletable files and folders" (entries with an immutable flag or a foreign owner that cannot be deleted via FTP even with correct permissions; only the host or root can fix this) and "Spam for search engines" (foreign sitemaps, robots.txt, ads.txt). Extended: the skimmer search reports WebSocket connections to unknown addresses and code that checks for an admin bar or a touch device; the process check shows the account's shared-memory segments.
- **Name is CLAUDIA everywhere**: The release package is now called CLAUDIA_v<version>.zip and unpacks into the folder CLAUDIA; the documentation is called CLAUDIA_Dokumentation.html. The guide, manual and installer also write the name and the folders Documents\CLAUDIA and %APPDATA%\CLAUDIA in capitals.
- **Intern**: New file claudia/checks/zusatz.py with pure assessment functions (evaluate_*), extended skimmer.py and konto.py.

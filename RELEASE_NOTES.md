# CLAUDIA 2.17.0 - Dashboard and more

- **Dashboard: overview, comparison, management**: New button "Dashboard". For each site it shows the latest state, the history as a curve, what is new, fixed or unchanged since the previous run, the number of fixed findings and carried-out actions, and hints (last run or backup too old). After connecting it also shows backups and quarantine folders on the server and offers creating a backup, deleting old backups and restoring or deleting quarantine. The history of a site can be deleted in two steps.
- **Follow-up check, check backup, export, support package**: In the dashboard the follow-up check reminds you: three days after a cleanup (e.g. malicious code removed, accounts blocked) a hint appears to check the site once more; the later run shows whether anything new has appeared since before the cleanup. "Check backup" opens the archives of a backup read-only and reports whether they can be read completely. The history can be saved as CSV and, per site, as a report (HTML) in the reports folder. The support package is a short text file for a GitHub issue.
- **Digital signature for updates and knowledge data (prepared)**: Program updates and new knowledge data (patterns, vulnerability lists in advisories.json) can be checked with a digital signature (Ed25519). CLAUDIA loads new knowledge data separately from the program and uses it from the next run. The check is switched on as soon as the author's public key is stored in the program; until then the checksum applies unchanged and nothing additional is loaded.
- **Internal**: New modules claudia/verlauf.py, claudia/signatur.py, claudia/wissen.py and claudia/support.py, new tests (history, dashboard extensions, signature, browser test of the dashboard); the list of not yet translated texts (tests/uebersetzung_offen.json) contains the new texts.

# CLAUDIA 3.0.0 - New interface: sidebar with logo, footer bar and the blue of the logo

- **New interface**: The interface now looks like a program instead of a website. On the left is a sidebar with the logo, the four steps (connection, select checks, check, result) and, at the bottom, Updates, Dashboard and Help. A fixed footer bar at the bottom shows the connection status, the language choice and the version; the previous notice text sits below the content. The colors come from the logo (the blue of the magnifier as accent, dark navy in dark mode, light blue in light mode). Nothing changes in functions, checks or reports. Why: The design "Leitstand Blau" was chosen because it can be used like a desktop program and keeps the dashboard and help always reachable.
- **Version number**: The first digit rises to 3 because the look of the program changes noticeably. Why: Users can see that it is a bigger step.

# CLAUDIA 3.0.0 - Neue Oberfläche: Seitenleiste mit Logo, Fußleiste und das Blau des Logos

- **Neue Oberfläche**: Die Oberfläche wirkt jetzt wie ein Programm statt wie eine Webseite. Links steht eine Seitenleiste mit dem Logo, den vier Schritten (Verbindung, Tests auswählen, Prüfung, Ergebnis) und unten Updates, Dashboard und Hilfe. Unten steht eine feste Fußleiste mit dem Verbindungsstatus, der Sprachwahl und der Version; der bisherige Hinweistext steht unter dem Inhalt. Die Farben stammen aus dem Logo (Blau der Lupe als Akzent, dunkles Marineblau im dunklen Modus, helles Blau im hellen Modus). Ändert sich nichts an Funktionen, Prüfungen und Berichten. Warum: Der Entwurf "Leitstand Blau" wurde gewählt, weil er sich wie ein Desktop-Programm bedienen lässt und das Dashboard und die Hilfe immer erreichbar bleiben.
- **Versionsnummer**: Die erste Ziffer steigt auf 3, weil sich das Aussehen des Programms deutlich ändert. Warum: Nutzer erkennen so, dass es ein größerer Schritt ist.

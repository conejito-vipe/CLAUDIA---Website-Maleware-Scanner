# CLAUDIA 3.1.0 - Dashboard with charts, help in the main window, installation check and fixes

- **Dashboard with charts**: The dashboard now opens in the main window, like the check. At the top are key figures, below them bars per site, an analysis in sentences, a history chart of critical findings and notices, and the sites in detail. The findings are clickable and show what is checked and why it matters. Why: The overview was only text and did not show its meaning at a glance.
- **Help in the same window**: Handbook, check catalogue and change log open in the main window with the same sidebar, no longer in a separate window. Why: A second window did not fit the rest of the interface.
- **Interface**: The sidebar has icons with text underneath and adapts to the screen height without its own scroll bar. Language, help and connection are at the top. The status bar shows only the status. The inner area is dark, the blue comes from the logo. The version now appears only in the title bar. Why: The layout should match the agreed design "Leitstand Blau".
- **Updates: loading indicator**: While the update search runs, a loading indicator appears. The text "null" in the installed version display is gone. Why: A bug in the display of the installed version.
- **Install security extension**: The "Install" button is now directly next to the extension, not below the list. The confirmation appears at the bottom as before. Why: You should be able to install the tool you chose.
- **Joomla: automatic updates stay on when the API is switched off**: The action "Switch off Joomla API" no longer switches off the two plugins of the update service. Automatic core updates keep running. Why: The API plugins and the update service plugins overlapped, so switching off the API also switched off automatic updates.
- **Joomla: installing extensions (e.g. JCE)**: The package is first downloaded to the server, the checksum from the publisher's manifest is compared, and only then installed. If the checksum is missing or wrong, nothing happens. Why: Installing directly from the link failed for JCE 3.0.6.
- **Check the installation**: CLAUDIA compares the program's files with PRUEFSUMMEN.txt. If a file is missing or changed, a notice with the list appears at the top. If the list itself is missing, this is stated. Why: Missing files went unnoticed before.
- **Setup**: The finish page shows the CLAUDIA logo. Before the end, a page explains the Windows message "Windows protected your PC" with the picture. Setup also recognises an older version when it has no registry entry (e.g. the Python edition). Why: The message unsettles users, and an older version was not recognised.

# CLAUDIA 3.1.0 - Dashboard mit Diagrammen, Hilfe im Hauptfenster, Prüfung der Installation und Fehlerbehebungen

- **Dashboard mit Diagrammen**: Das Dashboard öffnet sich jetzt im Hauptfenster wie die Prüfung. Oben stehen Kennzahlen, darunter Balken je Seite, eine Auswertung in Sätzen, ein Verlaufsdiagramm mit kritischen Funden und Hinweisen und die Seiten im Detail. Die Befunde sind anklickbar und zeigen, was geprüft wird und warum es wichtig ist. Warum: Die Übersicht war nur Text und hatte keine Aussage auf einen Blick.
- **Hilfe im selben Fenster**: Handbuch, Prüfkatalog und Änderungsverlauf öffnen sich im Hauptfenster mit derselben Seitenleiste, nicht mehr in einem eigenen Fenster. Warum: Ein zweites Fenster passte nicht zur übrigen Oberfläche.
- **Oberfläche**: Die Seitenleiste hat Symbole mit Text darunter und passt sich der Bildschirmhöhe an, ohne eigenen Scrollbalken. Sprache, Hilfe und Verbindung stehen oben. Die Fußleiste zeigt nur den Status. Der Innenbereich ist dunkel, das Blau kommt aus dem Logo. Die Version steht nur noch in der Titelleiste. Warum: Das Layout sollte dem festgelegten Entwurf "Leitstand Blau" entsprechen.
- **Updates: Ladeanzeige**: Während die Updatesuche läuft, erscheint eine Ladeanzeige. Der Text "null" bei der Anzeige der installierten Version ist weg. Warum: Ein Fehler bei der Anzeige der installierten Version.
- **Sicherheits-Erweiterung installieren**: Der Knopf "Installieren" steht jetzt direkt bei der Erweiterung, nicht unter der Liste. Die Bestätigung erscheint wie bisher unten. Warum: Man sollte beim gewünschten Werkzeug installieren können.
- **Joomla: Automatische Updates bleiben beim Abschalten der API an**: Die Aktion "Joomla-API abschalten" schaltet die zwei Plugins des Update-Dienstes nicht mehr aus. Die automatischen Core-Updates laufen damit weiter. Warum: Die API-Plugins und die Plugins des Update-Dienstes überschnitten sich. Dadurch ging mit der API auch die Automatik aus.
- **Joomla: Erweiterungen installieren (z. B. JCE)**: Das Paket wird zuerst auf dem Server geladen, die Prüfsumme aus dem Herstellermanifest wird verglichen und erst dann installiert. Fehlt die Prüfsumme oder ist sie falsch, passiert nichts. Warum: Die Installation direkt aus dem Link schlug bei JCE 3.0.6 fehl.
- **Installation prüfen**: CLAUDIA vergleicht die Dateien des Programms mit PRUEFSUMMEN.txt. Fehlt eine Datei oder ist sie verändert, erscheint oben eine Meldung mit der Liste. Fehlt die Liste selbst, wird das gesagt. Warum: Fehlende Dateien blieben bisher unbemerkt.
- **Setup**: Auf der Abschlussseite steht das CLAUDIA-Logo. Vor dem Abschluss erklärt eine Seite die Windows-Meldung "Der Computer wurde durch Windows geschützt" mit dem Bild dazu. Das Setup erkennt eine ältere Version auch dann, wenn sie keinen Registry-Eintrag hat (z. B. die Python-Fassung). Warum: Die Meldung verunsichert Nutzer, und eine ältere Version wurde nicht erkannt.
